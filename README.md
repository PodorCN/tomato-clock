# 🍅 Lofi Pomodoro | 高颜值沉浸式伴学番茄钟

> 专为深度工作与专注学习设计的高颜值全宽番茄时钟。集成 **B站 Lofi Girl / 24小时自习室白噪音联动**，支持专注时自动启播，休息与结束时自动停播关闭；全宽沉浸式毛玻璃美学设计，支持零配置直接部署在 GitHub Pages！

---

## ✨ 核心特性

- 🎨 **极具美感的全宽设计 (Full-Width Aesthetic)**
  - 沉浸式宽屏视觉，支持 4K 带宽屏、笔记本和移动端自适应。
  - 动态氛围背景引擎：**温暖自习室**、**雨夜咖啡馆**、**霓虹晚霞**、**竹林清风**、**静谧星河**、**极简暗黑** 6 款精调主题。
  - Canvas 物理粒子与雨滴氛围特效（支持一键开闭，页面隐藏时智能休眠省电）。
  - 流畅的 SVG 环形进度条与柔和呼吸光晕。

- 📺 **Bilibili Lofi 伴学白噪音智能联动**
  - **专注时自动播放**：点击“开始专注”，自动开启 B 站伴学直播间/视频。
  - **休息/到期时自动关闭**：25 分钟专注结束或进入 5 分钟休息时，**立即切断音频并关闭伴学**，无缝衔接休息。
  - **双重播放模式**：
    - **页面内嵌模式**：右侧伴学面板无缝内嵌播放。
    - **独立伴侣小窗模式**：自动弹窗，并在休息时**由程序自动关闭小窗**！
  - **多源支持**：内置 B站 24h 伴学自习室直播间、经典 Lofi 伴学视频、雨声咖啡厅及 YouTube 官方电台；支持用户自定义输入任意 B站房间号或 BV 号！

- ⏱️ **标准与自定义番茄工作法**
  - 经典循环：25 分钟专注 + 5 分钟短休，每 4 个番茄钟自动进入 15 分钟长休。
  - 快捷预设：`25/5 经典`、`50/10 深度`、`45/15 心流`、`90/20 攻坚`。
  - 完全自定义：可在设置面板随意调整专注、短休、长休时长，并可开启“自动流转”模式。

- 🔔 **零依赖本地合成声音引擎 (Web Audio API)**
  - 鸣钟提醒：528Hz 舒缓颂钵禅音（专注完成）、清脆上扬马林巴编钟（休息结束），纯算法实时合成，无需等待外部音频加载。
  - 本地自然白噪音混音：细雨、壁炉柴火、咖啡厅人声、海浪，可与 B站 伴学叠录或独立播放。
  - 系统级通知：支持浏览器桌面通知弹窗，切换到其他软件或全屏写代码也能及时收到提醒。

- 🧘 **极简沉浸禅意模式 (Zen Mode & Fullscreen)**
  - 按快捷键 `Z` 瞬间隐藏所有杂乱侧边栏与按钮，只留下大字时钟与呼吸光晕。
  - 按快捷键 `F` 开启无边框全屏。

- 📝 **专注意图与微目标备忘**
  - 顶部直接填写“当前专注目标”，拒绝走神。
  - 快捷今日 Todo 清单，打勾即刻归档。

## 🚀 GitHub Pages 极速部署指南

本项目采用纯静态架构（纯原生 HTML5 + CSS3 + Modular JS + Tailwind Utilities），**零构建步骤、零环境依赖**，开箱即用：

### 方法一：GitHub 页面直接部署（最简推荐）
1. 将当前代码提交并推送至你的 GitHub 仓库（例如 `main` 分支）：
   ```bash
   git add .
   git commit -m "feat: initial release of aesthetic lofi pomodoro clock"
   git push origin main
   ```
2. 打开 GitHub 仓库页面，点击 **Settings** -> **Pages**。
3. 在 **Build and deployment** 下的 **Source** 选择 **Deploy from a branch**。
4. Branch 选择 `main`，目录保持 `/ (root)`，点击 **Save**。
5. 稍等约 1 分钟，页面上方就会生成专属的访问链接（例如：`https://<你的用户名>.github.io/tomato-clock/`）！

### 方法二：GitHub Actions 自动部署
仓库根目录已内置 `.github/workflows/pages.yml`，在 GitHub 仓库 **Settings** -> **Pages** 中将 **Source** 选为 **GitHub Actions** 即可实现每次 push 自动发布。

## 🛠️ 本地预览

直接双击打开项目根目录下的 `index.html`，或者在终端运行轻量静态服务器：

```bash
# Python
python -m http.server 8080

# 或 Node.js
npx serve .
```
然后在浏览器中打开 `http://localhost:8080` 即可享受完整的番茄伴学体验。
